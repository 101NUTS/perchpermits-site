How the data is handled

Everything comes from government public records: Metro Nashville's open data portal and the Metro ePermits public case search. Building permits are public records under Tennessee's Public Records Act. Nothing is scraped from private sites, no field is guessed (missing values are null), and sources are read politely at one request per second. If Metro changes a field, the tool stops rather than returning bad data.

Perch Permits republishes public permit data from Metro Nashville's open data portal and ePermits. Support for either tool is through the Issues tab on its Apify Store page.
