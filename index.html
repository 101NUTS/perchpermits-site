Perch Data has closed

Perch Data stopped operating on 21 September 2026. The data tools it published on Apify Store — Kalshi weather markets, Polymarket weather markets, tennis odds, Nashville building permits, kitchen floor-plan takeoffs and Apify Store trends — have been retired and are being removed from the store. The two prediction-market tools no longer return data.

Nothing is for sale here any more, and no new data is collected. If you used one of the tools, thank you.
